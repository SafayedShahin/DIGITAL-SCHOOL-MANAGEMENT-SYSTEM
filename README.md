# DIGITAL-SCHOOL-MANAGEMENT-SYSTEM
A Complete Digital School Management System built with Python, Flask, and SQLite. Manage students, teachers, admissions, attendance, examinations, results, fees, accounts, and more. Customizable for schools across Bangladesh.


DIGITAL SCHOOL MANAGEMENT SYSTEM
Complete Digital Solution for Bangladeshi Schools

Smart School Management for a Better Future.

1. PROJECT OVERVIEW

Digital School Management System is a web-based application designed to simplify and digitize the daily academic, administrative, and financial activities of schools in Bangladesh.

The system is developed using Python, Flask, SQLite, HTML, CSS, and JavaScript.

The main objective is to provide schools with a centralized platform to manage students, teachers, admissions, attendance, examinations, results, fees, accounts, class routines, notices, and other essential school activities.

The project is initially being developed for Fordabad Ideal School.

However, the system is designed with future customization in mind so that it can be adapted for other schools by changing their school name, logo, address, contact information, academic settings, and branding.

The goal is to develop one reusable School Management System that can serve different educational institutions in Bangladesh.

15. INSTALLATION AND SETUP
Clone Repository


git clone YOUR_GITHUB_REPOSITORY_URL
Navigate to Project


cd digital-school-management-system
Create Virtual Environment


python -m venv venv
Activate Virtual Environment

Windows:


venv\Scripts\activate
Linux / macOS:


source venv/bin/activate
Install Dependencies


pip install flask python-dotenv
Install any additional dependencies required by the project.

Configure Environment

Create a .env file.

Example:


SCHOOL_SECRET_KEY=your-secure-secret-key
SCHOOL_DB_PATH=school.db
Never upload real production secrets or credentials to GitHub.

Run Application


python app.py
Open in Browser


http://127.0.0.1:5000
